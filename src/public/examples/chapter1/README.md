# 第1章「仲間スライム、誕生！」

- `starter/`：勇者と敵スライムの戦闘。
- `task1/`：仲間スライム追加。`FriendlySlime` によるコピー方式の例。
- `task2/`：スライム共通攻撃ダメージ5→7の変更。
- `solution/`：敵と仲間に同一 `Slime` クラスを使用。`team` は未導入。

コピー方式は2か所、共通化後は1か所の修正。受講者の負担感は未実測。`solution/` と第2章 `starter/` の**JSは一致、HTMLはページタイトルが異なる**（2026-11-03再確認）。2026-10-24のHTML完全一致は旧版の記録。

コピー方式は唯一解ではない。ターン制は暫定。実ブラウザ操作・配布用課題文・講師台本は未完了。

## 後続改修の反映（2026-10-24）

第1章の全段階で、キャラクターカード（絵文字・名前・HP）をJavaScriptの配列ループで動的生成する。第1章ではteam属性を導入しない。戦闘ログはターン番号ごとにまとめ、最新ターンを先頭に表示し、リセットで番号を初期化する。第2章starterにも同じ表示・ログ処理を引き継ぐ。

## 表示用プロパティ（2026-10-24）

第1章から第4章まで、キャラクターの絵文字は各インスタンスの `sprite` プロパティで保持し、`render()` は `actor.sprite` または `character.sprite` を表示する。スライムの絵文字は生成時の引数で指定する。表示用の補助データとして扱い、第2章の所属判定の学習テーマを先取りする解説は行わない。画像管理クラスは今回導入しない。
