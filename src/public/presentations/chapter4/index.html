歴史の一場面

エーリヒ・ガンマ／リチャード・ヘルム／ラルフ・ジョンソン／ジョン・ブリシディース

「Favor object composition over class inheritance.」

1994年の『Design Patterns』では、クラス継承だけでなく、オブジェクトを組み合わせる設計が重視された。部品を外から渡して組み合わせる今回の改善例にも通じるが、依存性注入と同義ではない。

関連資料：E. Gamma et al., Design Patterns: Elements of Reusable Object-Oriented Software (1994)
