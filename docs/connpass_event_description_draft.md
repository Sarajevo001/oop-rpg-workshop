# 【大阪開催：ハンズオン勉強会】RPGで学ぶ！プログラム改造ハンズオン
JavaScriptでゲームを改造しながら、変更しやすいプログラムの作り方を体験しよう！

# はじめに

今回のテーマは、**「RPGで学ぶ！プログラム改造ハンズオン」**です！🎮

簡単なRPGのプログラムを、次々に登場する追加仕様に合わせて改造していきます。

「仲間のスライムを追加してほしい！」
「敵と味方を区別して攻撃できるようにしてほしい！」
「仲間をプレイヤーが操作したり、コンピューターに任せたりしたい！」

一つずつ機能を追加していくと、最初は簡単だったプログラムが、だんだん複雑になっていくことがあります。

そんなとき、どうすれば修正しやすいプログラムになるのでしょうか？

今回のハンズオンでは、実際にコードを書き換えながら、**プログラムを改造する楽しさと、変更しやすいコードを考える面白さ**を体験していただきます。

完成済みのサンプルプログラムを用意していますので、ゼロからゲームを作る必要はありません。

一緒に楽しくプログラムを改造していきましょう！😊

# 👤 こんな人におすすめ

- JavaScriptを勉強していて、実際にプログラムを改造してみたい人
- プログラムは書けるけれど、修正しやすいコードの作り方に興味がある人
- 仕様変更のたびに、あちこち修正するのが大変だと感じたことがある人
- ゲームを題材に、プログラムの仕組みを楽しく学びたい人
- AIが生成したコードを、そのまま使うだけでなく、自分でも理解して改善できるようになりたい人

JavaScriptの変数、関数、条件分岐など、基本的な構文を理解している方を想定しています。

クラスについては、ハンズオンの最初に簡単な説明を行いますので、詳しく知らなくても大丈夫です。

# 🗒️ ハンズオンの内容

**1. RPGのプログラムを動かしてみよう**

まずは、勇者とスライムが登場する簡単なRPGを動かします。

プログラムの構造を確認しながら、JavaScriptのクラスやインスタンスの基本を紹介します。

**2. 仲間のスライムを追加しよう**

敵として登場するスライムを参考に、味方として戦うスライムを追加します。

さらに攻撃の仕様を変更してみると、同じようなコードを何か所も修正する必要が出てきます。

もっと簡単に変更できる方法を考えてみましょう。

**3. 敵と味方を区別できるようにしよう**

仲間が増えると、誰を攻撃できるのかを判断する処理も必要になります。

新しいキャラクターを追加したときにも対応しやすいように、敵と味方の判定方法を改善していきます。

**4. キャラクターの操作方法を切り替えよう**

仲間のスライムをプレイヤーが操作したり、コンピューターに任せたりできるようにします。

操作方法を変更するたびにキャラクターのプログラムを書き換えなくても済む方法を考えます。

**5. 敵の攻撃パターンを改造しよう**

敵のスライムが攻撃対象を記憶したり、ほかのスライムと同じ対象を狙ったりする機能を追加します。

少し複雑な仕様にも対応できるように、プログラムの役割を整理していきます。

**6. 改造したプログラムを振り返ろう**

今回の改造で、どんなところが面倒だったのか、どうすれば修正しやすくなったのかを振り返ります。

実際に体験したことをもとに、これからのプログラミングにも役立つ考え方を紹介します。

# 🗒️ 今回使用する技術

**【HTML / JavaScript】**

ブラウザ上で動作するRPGを使用します。

JavaScriptでキャラクターの動作や攻撃処理を変更し、プログラムの動きがどう変わるのかを確認します。

特別なフレームワークは使用しません。

**【JavaScriptのクラス】**

勇者やスライムなどのキャラクターを表現するために使用します。

クラスを使ったプログラムの基本については、最初に簡単な説明を行います。

# 🗒️ 当日の進め方

あらかじめ用意したRPGのプログラムを使い、追加仕様に合わせて少しずつコードを改造していきます。

各ステップでは、まず変更内容を説明し、参加者の皆さんに実際に修正していただきます。

その後、別の実装方法も紹介しながら、変更前後の違いを確認します。

途中で手が止まってしまっても、各段階のサンプルコードを使って続きから参加できるようにする予定です。

限られた時間で進めるため、すべての課題を完成させる必要はありません。実際に試しながら、どんな問題が起きるのかを体験することを大切にします。

**所要時間は150分を予定しています。**
