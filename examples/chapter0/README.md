**進行：正解提示 → 追加解説。演習なし。** 目安は導入・環境確認と合わせて15分（未検証）。

## 正解提示（講師が見せる）
1. `class Hero` は「勇者のインスタンスを作るための定義」。`class Slime` も同様。
2. `new Hero("勇者")` で勇者インスタンスを生成する。`new Slime("敵スライム")` で敵スライムを生成する。
3. `name` と `hp` は各インスタンスのプロパティ。異なるインスタンスはそれぞれの値を持つ。
4. `attack(target)` はメソッド。勇者が敵スライムに攻撃すると、敵スライムのHPが30から22に変化する。
5. 次章では同じ考え方を使って「仲間スライム」を増やす。ここでは継承、`team`、DIを教えない。

## 追加解説（歴史の話）
Simula 67 はクラスやオブジェクトの歴史を語る際の代表的な言語。もともとシミュレーションのモデル化という文脈がある。**具体的な人物名、発表年の原典、引用文は未検証**のため、投影用の歴史スライドには確定引用として掲載しない。
