# 第1章・手順③：課題の再現（講師用検証コード）

企画書 v0.8 に従った、**コピー方式を選んだ場合の一実装例**。受講者にコピーを強制するものではない。

- `task1/`：敵用 `Slime` を参考に `FriendlySlime` を追加。勇者と仲間スライムが敵スライムを攻撃する。
- `task2/`：共通攻撃仕様を「スライムの通常攻撃ダメージ5→7」に変更。

## 修正負担の測定
`task1/game.js` と `task2/game.js` の差分では、**攻撃ダメージ定数の変更が2か所**（`Slime.attack` と `FriendlySlime.attack`）。共通化後は1か所を目指す。

注意：2か所だけでは「イラッと」を十分に生むとは限らない。これは**重複が発生することの技術的確認**であり、受講者の心理的負担の実測ではない。今後のリハーサルで検証する。
