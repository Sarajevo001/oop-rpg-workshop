# 第2章 改善後コード（M1手順⑥）

第1章の完成版 `Slime` を継承せず、同一クラスのまま `team` 属性を追加する。

- 勇者、魔法使い、仲間スライム：`friend`。
- 敵スライム：`enemy`。
- `Slime.canAttack(target)` は `this.team !== target.team`。
- クラス列挙、グローバルな個体参照の比較を削除。
- `team` は攻撃可能性の判定用で、操作方法（プレイヤー/CPU）の選択には使用しない。
- 同じチームへの攻撃不可、異なるチームへの攻撃可を前提とする。死亡済み対象の判定等は本段階の仕様外。
- 実ブラウザの操作と受講者負担感の検証は未実施。第1章終了コードと第2章開始コードの一致は、第2章が第1章の `Slime` の構造を保ち、課題1で攻撃可否だけを追加することによって確認する。
