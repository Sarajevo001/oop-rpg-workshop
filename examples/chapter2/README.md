## team属性とコレクション管理

改善版では勇者・魔法使い・仲間スライム・敵スライムを単一の `characters` 配列に格納する。JavaScriptでは異なるクラスのインスタンスも同じ配列に格納でき、共通の `team` 属性で所属を判定して `filter()` で抽出できる。生存判定には `hp > 0` を併用する。表示も配列から生成し、個体ごとの表示処理を追加しない。

この変更は第2章の `solution/` から導入する。第1章の完成版と第2章の開始版は変更しない。第2章の完成版と第3章の開始版はHTML・JS同一。
