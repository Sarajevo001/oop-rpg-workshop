# 第2章 課題1・2の再現（M1手順⑤）

- 出発点：`examples/chapter1/solution/`。同じ `Slime` クラスから敵・仲間を生成。
- `task1/`：`Slime.canAttack(target)` を `target instanceof Hero` で実装。両スライムは勇者のみ攻撃でき、スライム同士は攻撃不可。したがって仲間スライムはこの段階では敵を攻撃できない（新要求は課題2）。
- `task2/`：`Wizard` を追加。敵スライムは勇者・魔法使いを攻撃可能、仲間スライムは敵スライムのみ攻撃可能。スライム同士は一般には攻撃不可という課題1のルールに、敵味方の例外を加える。
- 課題2の `canAttack` は、`this === friendlySlime`、`this === enemySlime` という**個体参照への依存**と、`Hero` / `Wizard` の**クラス列挙**を持つ。これが手順⑥で `team` に置き換える対象。
- 現時点では `team` は未導入。コピーした別スライムクラスも未導入。
- 戦闘画面は簡易確認用。課題1では仲間スライムの攻撃が拒否される様子をログで示す。
