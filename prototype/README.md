# RPG戦闘ゲーム 試作（改善後の構造）

これは4章構成の**技術的成立性を調べるための試作品**です。参加者用の開始コードや完成教材ではありません。

## 実行方法
`index.html` をブラウザで開きます。外部ライブラリ、ビルド、サーバーは不要です。

## 対応する構想
- 第1章: `calculateDamage` でダメージ計算を共通化
- 第2章: `Character` でHPなどの状態と操作をまとめる
- 第3章: `performAction(action)` へ関数を渡す
- 第4章: `Hero` に武器インスタンスを渡し、剣・弓・杖が各自の消耗状態を管理する
